# Zodiaque & 28 Lettres — Application V1

Application web autonome construite à partir du référentiel final.

## Modules disponibles
- Accueil
- 28 lettres
- Calcul Abjad Maghrébin
- Analyse des 4 éléments
- 12 signes du zodiaque
- Planètes et luminaires
- Correspondances
- Phases lunaires
- 28 jours lunaires
- Profil local
- Sources
- Méthode et limites
- État du référentiel

## Principes
- Abjad Maghrébin uniquement.
- Classification élémentaire 7/7/7/7.
- Aucune correspondance lettre-signe-planète inventée.
- Astronomie et astrologie séparées.
- Les données symboliques sont étiquetées comme traditionnelles/non scientifiques.

## Déploiement
Le projet est autonome et compatible avec GitHub Pages. Les données JSON sont chargées localement via HTTP(S).
