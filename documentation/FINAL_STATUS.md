# Statut final du package

## Package canonique unique

`Zodiaque_28_Lettres_PACKAGE_FINAL.zip` est le **seul package à conserver** pour la construction.

Les anciennes archives V1, V2 et BUILD FINAL sont historiques et ne doivent pas être empilées.

## Ce qui est inclus

- application web responsive ;
- référentiel Abjad Maghrébin ;
- 28 lettres ;
- classification élémentaire 7/7/7/7 ;
- signes, modalités, planètes ;
- phases et jours lunaires ;
- calculateur Abjad ;
- analyses élémentaires ;
- correspondances sans invention ;
- profil local ;
- module astronomique ;
- documentation ;
- tests ;
- PWA ;
- manifeste et versionnement.

## Moteur astronomique

Astronomy Engine 2.1.19 est déclaré comme dépendance et chargé par le build navigateur via une URL versionnée. Le projet officiel fournit un build navigateur autonome et documente son utilisation côté client. La version 2.1.19 est la release retenue ici.

## Limite volontaire

Ce package est le **package complet de construction de l'application**. Les fonctions qui nécessitent un backend sécurisé (comptes, synchronisation distante, administration distante, paiements, notifications serveur, API publique) ne sont pas simulées comme si elles étaient déjà opérationnelles.

Aucune nouvelle archive intermédiaire n'est nécessaire pour commencer la construction.
