# Limites astronomiques

Cette version finale ne prétend pas être un moteur d'éphémérides.

## Non promis par cette version
- positions planétaires de haute précision ;
- ascendant calculé avec précision ;
- maisons astrologiques calculées avec précision ;
- aspects astronomiques/astrologiques précis ;
- lever/coucher lunaire précis ;
- éphémérides professionnelles.

Ces fonctions peuvent être ajoutées ultérieurement avec un moteur astronomique identifié, documenté et testé.

## Pourquoi cette séparation
L'objectif est de ne pas présenter un calcul approximatif comme une mesure astronomique exacte.
