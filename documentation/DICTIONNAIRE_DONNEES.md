# Dictionnaire de données — version finale

## Règle générale
Une valeur peut être:
- **FOUNDATION** : donnée verrouillée par le cahier des charges.
- **REFERENCE** : donnée descriptive soutenue par une source.
- **TRADITIONAL** : donnée astrologique/traditionnelle, explicitement non scientifique.
- **UNDEFINED** : donnée non attribuée faute de source/choix de tradition.

## Fichiers
- `lettres.json` : 28 lettres, valeurs Abjad Maghribi et éléments.
- `elements.json` : quatre éléments et leurs sept lettres.
- `modalites.json` : cardinal/fixe/mutable.
- `zodiaque.json` : 12 signes, noms, éléments, modalités, polarités, maîtres et descriptions.
- `planetes.json` : corps utilisés dans le référentiel astrologique.
- `phases_lunaires.json` : définitions astronomiques des huit phases.
- `jours_lunaires.json` : 28 emplacements symboliques; aucune signification universelle inventée.
- `correspondances.json` : matrice lettre → signe → planète, explicitement indéfinie tant qu'une source n'est pas choisie.
- `sources.json` : provenance des données.
